# Referencias de diseño

Coloca aquí capturas, mockups o exportaciones (por ejemplo desde Muse) que sirvan de referencia visual para construir la interfaz.

Estos archivos tienen prioridad sobre los wireframes de baja fidelidad enlazados en el `README.md` principal, pero las reglas de `DESIGN.md` (paleta, tipografía, layout) siguen aplicando salvo que se indique explícitamente lo contrario — el objetivo es evitar que cada referencia nueva reintroduzca decisiones visuales genéricas por defecto.
